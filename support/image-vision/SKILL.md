# Image Vision support

This support directory contains the credential-free Python helper used by `dsh-image-vision`. The installing AI copies it into a user-level Skill directory, normally `~/.zcode/skills/image-vision`. Configure the user's own DashScope key through `DASHSCOPE_API_KEY` or `~/.config/image-vision/config.json`; never add a key to this repository. Runtime history belongs in the installed Skill directory and is never synchronized back.
